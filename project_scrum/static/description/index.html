Project Scrum: Scrum Module

Using Scrum to plan the work in teams.

Odoo 18.0· Project· by Vertel Sverige AB

Overview

Using Scrum to plan the work in teams.

It introduces the model(s) ProjectUserStories, ScrumSprintTags, ScrumSprint to handle this workflow.

It extends Odoo's analytic lines, tasks, projects.

Key Features

Dedicated data model

Adds its own models: ProjectUserStories, ScrumSprintTags, ScrumSprint.

Guided wizards

Step-by-step dialogs for data entry.

Actions

Adds action_assign_to_me, action_view_sprint_calendar, action_create_sprint_calendar.

UI integration

Extends 4 view(s) in the Odoo interface.

Module Graphics

Dependencies

  • project
  • mail
  • hr_timesheet
  • sales_team
  • calendar
  • web_mermaid
  • project_task_closed

Requires Odoo 18.0 or later.

Installation

Install the module project_scrum from the Odoo Apps menu, or deploy it via the Vertel SaltStack pipeline.
